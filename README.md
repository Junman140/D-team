# D—TEAM Studio

The D-Team public website and production platform project. This project is separate from the legacy YAW app in `../YAW`.

## Local development

Requires Node.js, pnpm, and PostgreSQL for private Studio authentication and inquiry submissions. Public pages render without PostgreSQL, but inquiry submission is unavailable until `DATABASE_URL` and `BETTER_AUTH_SECRET` are set; `/studio` redirects to sign-in.

```bash
pnpm install
cp .env.example .env
# Set DATABASE_URL and BETTER_AUTH_SECRET in .env before using Studio.
pnpm db:migrate:deploy
pnpm dev
```

Open `http://localhost:3000`.

Set `SITE_URL` to the canonical public origin for `robots.txt` and `sitemap.xml`. Generate a secret with `pnpm auth:secret` and put it in `.env` as `BETTER_AUTH_SECRET`; never commit it. After migrations have been applied, run `pnpm auth:create-admin` in an interactive terminal to create the first administrator. The command prompts for an email address and password instead of putting credentials in shell history. The first owner-supplied administrator email is `junmanpi@gmail.com` — its password is entered interactively at the prompt and is intentionally not stored anywhere in the repository, shell history, or documentation. More administrator emails may be supplied later. Sign in at `/studio`; the first administrator can create the D-Team Production workspace, which assigns the organization owner role. Public sign-up is disabled, and the administrator permissions do not include user impersonation. For schema changes during local development, use `pnpm db:migrate:dev`; use `pnpm db:migrate:deploy` to apply committed migrations. No database provider or deployment target has been selected yet, and no production database has been created or migrated.

The public inquiry endpoint rate-limits hashed email and client-IP buckets. A production reverse proxy must remove client-supplied forwarding headers and set a canonical `x-real-ip`; without it, the per-email limit remains active but the per-IP limit cannot be applied.

`PUBLIC_INQUIRIES_ENABLED` defaults to `false`. Set it to `true` only after the service descriptions, privacy contact, and retention policy have been approved; otherwise the quote page shows a paused state and the endpoint returns 503.

Studio media uploads go directly from the browser to a private Vercel Blob store, with a short-lived server-issued upload token scoped to staff permissions. Files are limited to supported images, video, and PDF up to 50 MB. Authorized media reads receive a five-minute, single-file signed URL; image derivatives are generated when `ffmpeg`/`ffprobe` are available. Create a **private** Blob store in Vercel and connect it to this project to provision `BLOB_READ_WRITE_TOKEN`.

Public inquiry notifications use Gmail SMTP. Set `SMTP_HOST=smtp.gmail.com`, `SMTP_PORT=587`, `SMTP_USER`, `SMTP_PASS` (a Google App Password), optional `SMTP_FROM`, and `INQUIRY_NOTIFY_EMAIL`. Inquiry records are saved even if SMTP delivery fails; Studio records delivery status and permits staff retry. Keep `PUBLIC_INQUIRIES_ENABLED=false` until the deployment URL, database, privacy details, and email settings are configured, then set it to `true` to open submissions.
